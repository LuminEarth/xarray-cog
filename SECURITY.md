# Security reports

This project is in early development. Security fixes target the latest `main`; there is no supported older-release series or guaranteed response time.

If GitHub shows **Security → Report a vulnerability** for this repository, use that private reporting form. Otherwise, open an issue asking the maintainer to arrange a private reporting channel, without disclosing exploit details. Do not attach credentials, private S3 URLs, or sensitive datasets to public issues or logs.

Once a private channel is available, include the affected revision, a minimal non-sensitive reproducer, impact and relevant platform details. Ordinary bugs belong in GitHub issues.
